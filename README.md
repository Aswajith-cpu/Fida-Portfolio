# Fida Portfolio

A static portfolio website for a creative designer.

## Project Structure

- `index.html`: Main entry point.
- `assets/css/style.css`: Stylesheets.
- `assets/img/`: Images and placeholders.

## Features

- Responsive Design
- CSS Grid & Flexbox Layouts
- Dark Mode Aesthetic
- Semantic HTML5

## How to Run

Simply open `index.html` in your web browser.
